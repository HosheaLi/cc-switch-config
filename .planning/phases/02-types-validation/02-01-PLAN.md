    1. **EnvConfigSchema** (environment variables):

       export const EnvConfigSchema = z.object({
         ANTHROPIC_MODEL: z.string().optional(),
         ANTHROPIC_BASE_URL: z.string().url().optional(),
         ANTHROPIC_AUTH_TOKEN: z.string().optional(),

    2. **McpServerConfigSchema** (MCP server configuration):
       ```typescript
       export const McpServerConfigSchema = z.object({
         command: z.string(),
         args: z.array(z.string()).optional(),
         env: z.record(z.string(), z.string()).optional(),
         disabled: z.boolean().optional(),
       }).strict(); // Reject unknown keys per research
       ```

    3. **PermissionRuleSchema** (permission rules):
       ```typescript
       export const PermissionRuleSchema = z.object({
         allow: z.string().optional(),
         deny: z.string().optional(),
       }).strict().refine(
         data => data.allow !== undefined || data.deny !== undefined,
         "Permission rule must have 'allow' or 'deny'"
       );
       ```

    4. **HookConfigSchema** (hook configuration):
       ```typescript
       export const HookConfigSchema = z.object({
         match: z.string(),
         run: z.string(),
         timeout: z.number().int().positive().optional(),
       }).strict();
       ```

    5. **ClaudeSettingsSchema** (complete settings.json schema per D-02):
       ```typescript
       export const ClaudeSettingsSchema = z.object({
         version: z.number().int().optional(), // Config version field
         env: z.record(z.string(), z.string()).optional(), // Environment variables (key-value)
         model: z.string().optional(), // Default model
         mcpServers: z.record(z.string(), McpServerConfigSchema).optional(), // Named MCP servers
         permissions: z.array(PermissionRuleSchema).optional(), // Permission rules
         hooks: z.array(HookConfigSchema).optional(), // Hooks
       }).strict(); // Reject unknown keys - catches typos like 'modle'
       ```

    **Type Inference (per D-01):**
    ```typescript
    export type EnvConfig = z.infer<typeof EnvConfigSchema>;
    export type McpServerConfig = z.infer<typeof McpServerConfigSchema>;
    export type PermissionRule = z.infer<typeof PermissionRuleSchema>;
    export type HookConfig = z.infer<typeof HookConfigSchema>;
    export type ClaudeSettings = z.infer<typeof ClaudeSettingsSchema>;
    ```

    **Implementation Notes:**
    - Use `.strict()` on object schemas to reject unknown keys (Zod 4 API, not deprecated `.noUnknown()`)
    - Use `.passthrough()` on EnvConfigSchema to allow arbitrary environment variable keys
    - Add JSDoc comments for each schema explaining its purpose
    - Import Zod: `import { z } from 'zod';`
