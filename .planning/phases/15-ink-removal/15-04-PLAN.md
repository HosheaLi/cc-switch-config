# Plan 04: Migrate All chalk Imports to Theme Module

## Objective

将 CLI 层（commands + prompts + output）中所有剩余的 `chalk` import 替换为 `src/cli/theme/` picocolors 主题模块。完成后代码库不再包含任何 chalk 直接引用。

## Background

RESEARCH.md 发现 20 个文件仍使用 chalk。Plan 01 已处理 4 个 wizard 的 theme.ts 编译错误。本计划处理剩余的 10 个 command 文件、7 个 prompts 文件和 1 个 utils 文件。Phase 14 已建立完整的 `src/cli/theme/` 模块作为 chalk 的替代。

## Tasks

### Task 01: Migrate 5 command files chalk → theme

<read_first>
- src/cli/commands/switch.ts
- src/cli/commands/config.ts
- src/cli/commands/current.ts
- src/cli/commands/list.ts
- src/cli/commands/undo.ts
- src/cli/theme/index.ts (可用导出列表)
</read_first>

<action>
对 5 个 command 文件执行统一的 chalk → theme 迁移：

**导入替换：**
- `import chalk from 'chalk'` → `import { colors, formatters, separator } from '../theme/index.js'`（按需选择子集）

**调用替换（严格按 PATTERNS.md Pattern B 映射表）：**
- `chalk.green('✓ text')` → `formatters.success('text')`（✓ 已内置于 formatter）
- `chalk.green('text')` → `colors.success('text')`
- `chalk.red('✗ text')` → `formatters.error('text')`
- `chalk.red('text')` → `colors.danger('text')`
- `chalk.yellow('⚠ text')` → `formatters.warning('text')`
- `chalk.yellow('text')` → `colors.warning('text')`
- `chalk.gray('text')` → `colors.muted('text')`
- `chalk.cyan('text')` → `colors.accent('text')`
- `chalk.white('text')` → 普通文本或 `colors.foreground('text')`
- `chalk.bold('text')` → `colors.bold('text')`
- `chalk.cyan.bold('text')` → `colors.bold(colors.accent('text'))`
- `chalk.gray('─'.repeat(N))` → `separator(N)`

每个文件逐一检查所有 chalk 调用，确保映射正确，语义不变。
</action>

<acceptance_criteria>
- `grep -r "from 'chalk'" src/cli/commands/` 返回空
- `grep -r "import chalk" src/cli/commands/` 返回空
- `grep -r "chalk\." src/cli/commands/` 返回空
- 5 个文件均包含 `from '../theme/index.js'` 导入
- `npx tsc --noEmit` 对 5 个文件不报错
</acceptance_criteria>
