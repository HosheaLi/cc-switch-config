# Plan 01: Fix Broken Theme Imports (Wave 0 Blocker)

## Objective

修复 Phase 14-04 删除 `src/cli/prompts/utils/theme.ts` 后遗留的编译错误，使 TypeScript 编译通过。4 个 wizard 文件和 barrel export 仍引用已删除的 `theme.js`。

## Background

Phase 14-04 删除了 `src/cli/prompts/utils/theme.ts`（旧 chalk 主题文件），但未更新消费者。当前 `npx tsc --noEmit` 报 `TS2307: Cannot find module './theme.js'`。必须先修复此问题，后续所有任务才能在编译通过的基础上进行。

## Tasks

### Task 01: Update 4 wizard files to import from theme module

<read_first>
- src/cli/prompts/wizards/config-wizard.ts
- src/cli/prompts/wizards/main-wizard.ts
- src/cli/prompts/wizards/switch-wizard.ts
- src/cli/prompts/wizards/scan-wizard.ts
- src/cli/theme/index.ts (target module — source of truth for available exports)
</read_first>

<action>
对 4 个 wizard 文件执行以下修改：

1. **config-wizard.ts**: 删除 `import { styleSuccess, styleError, styleWarning, separator } from '../utils/theme.js'`，替换为 `import { formatters, separator as themeSeparator } from '../../theme/index.js'`。将 `styleSuccess(msg)` 替换为 `formatters.success(msg)`，`styleError(msg)` 替换为 `formatters.error(msg)`，`styleWarning(msg)` 替换为 `formatters.warning(msg)`，`separator()` 替换为 `themeSeparator()`。

2. **main-wizard.ts**: 同上替换。此外删除 `chalk.level = 0` 行（死代码，主题检测由 `src/cli/theme/detection.ts` 处理）。

3. **switch-wizard.ts**: 同上替换模式。

4. **scan-wizard.ts**: 同上替换模式。
</action>

<acceptance_criteria>
- `src/cli/prompts/wizards/config-wizard.ts` 不包含 `from '../utils/theme.js'`
- `src/cli/prompts/wizards/main-wizard.ts` 不包含 `from '../utils/theme.js'` 且不包含 `chalk.level`
- `src/cli/prompts/wizards/switch-wizard.ts` 不包含 `from '../utils/theme.js'`
- `src/cli/prompts/wizards/scan-wizard.ts` 不包含 `from '../utils/theme.js'`
- 4 个文件均包含 `from '../../theme/index.js'`
- `npx tsc --noEmit` 不报 TS2307 错误
</acceptance_criteria>
