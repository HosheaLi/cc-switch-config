    ```typescript

      switched: boolean;
      projectId: string | null;
      projectName: string | null;
      templateName: string | null;
      unregisteredDir: boolean;  // D-03: Found .claude but not registered

    ```

    Implement detectAutoSwitch(cwd: string, projectIndex: ProjectIndex, appState: AppState): Promise&lt;AutoSwitchResult&gt;
    - Get project by path using projectIndex.getByPath(cwd)
    - If found: Check if active project changed via appState.getActiveProject()
    - If not found: Check for .claude/settings.json existence (fs.pathExists)
    - Return result with switched=true only when project actually changed

    Implement applyAutoSwitch(result: AutoSwitchResult, appState: AppState): void
    - If result.projectId: appState.setActiveProject(result.projectId)
    - No file writes - just state update

    Implement formatSwitchMessage(result: AutoSwitchResult): string | null
    - Per D-02: Return null if no switch (silent mode)
    - Return "Switched to project: {name}" if switched
    - Return "Template: {templateName}" if template exists
    - Return "Found .claude directory. Register with: cc-config register" if unregisteredDir (D-03)
