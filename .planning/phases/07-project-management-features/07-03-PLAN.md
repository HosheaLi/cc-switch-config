    ```typescript
      ) {}
    }
    ```

    Implement exportProject(projectId: string): Promise&lt;ExportPayload&gt;
    - Get project by ID from projectIndex.getById(projectId)
    - Throw ServiceError if not found (PROJECT_NOT_FOUND)
    - Read project config via configService.readProjectConfig(project.path)
    - Get template if project.activeConfig via templateStore.get(project.activeConfig)
    - Build ExportPayload with metadata (version 1.0, exportedAt ISO, toolVersion 0.1.0)
    - Return payload

    Implement detectConflicts(imported: ClaudeSettings, existing: ClaudeSettings): ConflictField[]
    - Check env variables: for each key in imported.env, if existing.env[key] exists and differs
    - Check model field: if imported.model differs from existing.model
    - Check mcpServers: for each server name in imported.mcpServers, if existing differs
    - Return array of ConflictField with key, imported value, existing value

    Implement importProject(payload: unknown, targetPath: string, strategy: 'merge' | 'overwrite' | 'skip'): Promise&lt;void&gt;
    - Validate payload via ExportPayloadSchema.parse(payload)
    - Throw ServiceError if validation fails (IMPORT_INVALID)
    - Read existing config at targetPath
    - If strategy === 'overwrite': write parsed.data.settings directly
    - If strategy === 'merge' and existing: use deepMergeConfig(existing, parsed.data.settings)
    - If strategy === 'skip': do nothing
    - Create backup before write (per Safety-First)

    Export ExportService class and detectConflicts function.
