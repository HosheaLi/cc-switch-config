## Screen Overview

### Screen 1: ScanScreen (F10)

**Purpose:** Multi-select interface for registering newly discovered projects.

**Entry points:**
- TUI: ProjectListScreen press 'S' key → push('scan')
- CLI: `cc-config scan --root ~/code` → outputs to stdout

**Layout hierarchy:**
```
ScanScreen
├── Header (Text bold cyan: "Scan Results")
├── Count summary (Text dimColor: "X new projects found")
├── Project list (Box flexDirection="column")
│   ├── New projects (selectable, checkbox toggle)
│   │   └── Item line: "[ ]/[\u2713] {name} {path}"
│   └── Already registered (non-selectable, gray)
│       └── Item line: "(registered) {name}"
├── Selection summary (Text: "{count} selected")
├── Help text (Text dimColor: "Space: toggle | Enter: confirm | Esc: cancel")
```

**Reference:** Phase 06 ProjectListScreen layout pattern

### Screen 2: ImportConflictScreen (F13)

**Purpose:** Resolve import conflicts when imported config differs from existing.

**Entry points:**
- CLI: `cc-config import file.json` → if conflicts detected → launch TUI

**Layout hierarchy:**
```
ImportConflictScreen
├── Header (Text bold cyan: "Import Conflicts Detected")
├── Conflict count (Text dimColor: "X conflicting fields")
├── Conflict list (Box borderStyle="single", borderColor="yellow")
│   ├── Per conflict row:
│   │   ├── Field key (Text bold)
│   │   ├── Imported value (Text color="cyan")
│   │   ├── Existing value (Text color="yellow")
├── Resolution options (Box flexDirection="column", marginTop=1)
│   ├── Option 1: "[1] Merge all (preserve existing + add new)"
│   ├── Option 2: "[2] Overwrite all (replace with imported)"
│   ├── Option 3: "[3] Skip all (keep existing, discard import)"
├── Help text (Text dimColor: "1/2/3: select option | Esc: cancel import")
```

**Reference:** Phase 06 ConfirmScreen pattern (y/n → 1/2/3 options)

## Interaction Patterns

### Keyboard Navigation

**ScanScreen keyboard map:**

| Key | Action | Reference |
|-----|--------|-----------|
| Space | Toggle selection on focused item | D-09 checkbox pattern |
| Enter | Confirm registration (selected items) | U5 confirmation |
| Esc | Cancel, return to ProjectListScreen | U4 Escape to Cancel |
| ↑/k | Move focus up | U3 dual-mode navigation |
| ↓/j | Move focus down | U3 dual-mode navigation |

**Implementation:** Extend `useKeyInput` hook with `onToggle` callback for Space

**ImportConflictScreen keyboard map:**

| Key | Action | Reference |
|-----|--------|-----------|
| 1 | Select "Merge all" | D-07 resolution option |
| 2 | Select "Overwrite all" | D-07 resolution option |
| 3 | Select "Skip all" | D-07 resolution option |
| Esc | Cancel import entirely | U4 Escape to Cancel |

**Implementation:** Direct `useInput` for number keys (like ConfirmScreen uses y/n)

### State Management

**ScanScreen state:**
```typescript
interface ScanScreenState {
  results: ScanResult[];         // From ProjectService.scanProjects()
  selectedIndex: number;         // Currently focused item (new projects only)
  selectedPaths: Set<string>;    // Checked paths to register
}
```

**ImportConflictScreen state:**
```typescript
interface ImportConflictState {
  conflicts: ConflictField[];    // From detectConflicts()
  resolution: 'merge' | 'overwrite' | 'skip' | null;
}
```

### Navigation Integration

**Screen type extension:**
```typescript
// Extend useNavigation Screen type
export type Screen = 'list' | 'editor' | 'confirm' | 'template-select' | 'scan' | 'import-conflict';
```

**Navigation flow:**
- ProjectListScreen → press 'S' → push('scan') → ScanScreen
- ScanScreen → Enter → pop() → ConfirmScreen → confirm → register
- CLI import → conflicts → launchTUI('import-conflict') → ImportConflictScreen

## Integration Points

### TUI App Container (app.tsx)

```typescript
// Screen routing extension
switch (navigation.current) {
  case 'scan':
    return <ScanScreen results={scanResults} onConfirm={handleRegister} onCancel={navigation.pop} />;
  case 'import-conflict':
    return <ImportConflictScreen conflicts={conflicts} onResolve={handleImport} onCancel={handleCancelImport} />;
  // ... existing screens
}
```

### ProjectListScreen Extension

```typescript
// Add 'S' key handler for scan trigger
useInput((input, key) => {
  if (input === 'S' && isActive) {
    triggerScan();
    navigation.push('scan');
  }
}, { isActive: !isSearchMode });
```

### CLI Commands

| Command | TUI Trigger | Notes |
|---------|-------------|-------|
| `cc-config scan` | Optional `--tui` flag | Default CLI output, TUI on flag |
| `cc-config import file.json` | Automatic if conflicts | CLI proceeds if no conflicts |
| `cc-config export <id>` | No TUI | CLI only, outputs JSON file |
| `cc-config auto-check` | No TUI | Shell hook integration, silent mode |
