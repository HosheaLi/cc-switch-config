## Spacing Scale

Declared values (Ink Box padding/margin — multiples of 1, corresponding to terminal cell units):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 1 | Icon gaps, inline spacing |
| sm | 1 | Compact element spacing, Box padding={1} |
| md | 2 | Default element spacing, Box padding={2} |
| lg | 1-2 | Section margin between elements |
| xl | 2 | Major section breaks (marginTop={2}) |

Exceptions: Terminal spacing uses cell units (1 = one character width/height), not pixel multiples.

## Color Contract

Per existing project patterns and locked decisions:

| Role | Ink/chalk Value | Usage |
|------|-----------------|-------|
| Header | `color="cyan"` | Screen titles, section headers |
| Prompt | `color="yellow"` | User action prompts, interactive hints |
| Success | `color="green"` | Success messages, confirmation indicators |
| Error | `color="red"` | Error messages, destructive warnings |
| Diff Removed (D-01) | `color="red"` | Removed lines in unified diff |
| Diff Added (D-01) | `color="green"` | Added lines in unified diff |
| Dimmed | `dimColor` | Secondary text, descriptions, help |
| White | `color="white"` | Normal text (default) |

Border colors follow semantic context:
- `borderColor="yellow"` for preview/conflict boxes
- `borderColor="red"` for error/warning boxes
- `borderColor="cyan"` for header boxes
- `borderColor="gray"` for neutral boxes

Accent reserved for: Headers (cyan), Prompts (yellow), Success indicators (green) — not used for all interactive elements.

## Copywriting Contract

### DiffScreen (D-01, D-02, D-03)

| Element | Copy |
|---------|------|
| Header | `Changes to Apply` |
| Subheader | `--- settings.json (before)` / `+++ settings.json (after)` |
| Removed line format | `- {path}: {value}` |
| Added line format | `+ {path}: {value}` |
| Modified line format | Two lines: red `- {path}: {before}` then green `+ {path}: {after}` |
| Empty state (no changes) | `No changes detected — config unchanged` |
| Prompt | `Press Enter to apply, Escape to cancel` |

## UI Components

### DiffScreen (NEW)

**Purpose:** Unified diff display before template application (D-03 mandatory)

**Visual Pattern:**
- Full-screen layout (like ConfirmScreen)
- Header: `<Text bold color="cyan">Changes to Apply</Text>`
- Diff content box: `borderStyle="single" borderColor="yellow"`
- Line-by-line diff rendering (UnifiedDiff component)
- Bottom prompt: `<Text bold color="yellow">Press Enter to apply, Escape to cancel</Text>`

**Interaction Contract:**
| Key | Action |
|-----|--------|
| Enter | Apply changes (proceed to ConfigEditorScreen.apply) |
| Escape | Cancel (return to ConfigEditorScreen) |

**Integration:** Inserted between template selection and ConfigEditorScreen.apply

### ValidationErrorScreen (NEW)

**Purpose:** Full-screen error list display, block continuation (D-04, D-05)

**Visual Pattern:**
- Full-screen layout (like ConfirmScreen)
- Header: `<Text bold color="red">Validation Errors</Text>`
- Error list box: `borderStyle="single" borderColor="red"`
- Each error: `<Text>{symbol} {path}: {message}</Text>`
- Bottom prompt: `<Text bold color="yellow">Press Escape to return and fix errors</Text>`

**Interaction Contract:**
| Key | Action |
|-----|--------|
| Escape | Return to ConfigEditorScreen (D-05: no confirm option) |

**Critical:** NO 'y' confirm option per D-05 — user must fix errors before proceeding.

### UnifiedDiff Component (NEW)

**Purpose:** Diff rendering component for DiffScreen

**Visual Pattern:**
- Container: `<Box flexDirection="column">`
- Each removed line: `<Text color="red">- {path}: {value}</Text>`
- Each added line: `<Text color="green">+ {path}: {value}</Text>`
- Modified fields: Two lines (red then green)

**Data Contract:**
```typescript
interface DiffLine {
  type: 'added' | 'removed' | 'modified';
  path: string;
  value?: unknown;       // for added/removed
  before?: unknown;      // for modified
  after?: unknown;       // for modified
}
```

### Undo Trigger Integration

**CLI undo command (NEW):**
- Command: `cc-config undo`
- Output: Success message with backup details
- Error: "No backup available" if getLatestBackup returns null

**TUI 'U' key (ProjectListScreen modification):**
- Trigger: Press 'U' in ProjectListScreen
- Action: Call UndoService.undo(currentProject)
- Feedback: StatusBar shows "Restored from backup ({N} min ago)"
