<interfaces>
From PITFALLS.md Pitfall 1 (Config File Corruption):
- NEVER: fs.writeFile('config.json', JSON.stringify(data))
- ALWAYS: write to temp file, then rename atomically
- Pattern: tempPath = `${filepath}.tmp.${process.pid}`

From PITFALLS.md Pitfall 2 (TOCTOU Race Conditions):
- WRONG: check-then-act pattern
- RIGHT: Handle ENOENT errors gracefully in try/catch
- RIGHT: Use exclusive flags like 'wx' for atomic creation

From ARCHITECTURE.md Pattern 1 (Repository Pattern):
- Abstract file operations behind repository interface
- Methods: read(path), write(path, config), exists(path), backup(path)
</interfaces>
