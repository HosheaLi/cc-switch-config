- Store API tokens in tracked config -> Token leaked to Git
- Expose tokens in error messages -> Token in logs/screenshots
- Config files world-readable -> Other users read tokens

Key patterns:
- settings.local.json should be in .gitignore
- Mask tokens in display (show only last 4 chars)
- Check if file is tracked by git before writing tokens

<action>
Create src/lib/security/token-check.ts:

1. Import fs from 'fs-extra' and path from 'path'

2. Define constants:
   ```typescript
   const TOKEN_FILE = 'settings.local.json';
   const GITIGNORE = '.gitignore';
   ```

3. Implement isTokenFile(filepath: string): boolean
   - Check if filename is 'settings.local.json'
   - Return true/false

4. Implement maskToken(token: string): string
   - If token length < 4, return '****'
   - Otherwise, return `...${token.slice(-4)}`
   - Example: 'sk-ant-abc123' -> '...c123'

5. Implement checkGitTracking(projectDir: string, filepath: string): Promise<boolean>
   - Read .gitignore from projectDir
   - Check if filepath or 'settings.local.json' is in ignore patterns
   - Return true if ignored (safe), false if potentially tracked
   - Handle ENOENT (no .gitignore) - return false (potentially tracked)

6. Implement validateTokenSecurity(projectDir: string, filepath: string): Promise<{safe: boolean, warnings: string[]}>
   - Check isTokenFile(filepath)
   - If not token file, return {safe: true, warnings: []}
   - Check git tracking status
   - If tracked, return {safe: false, warnings: ['Token file may be tracked by git']}
   - Check file permissions (should be 600)
   - Add permission warning if not 600
   - Return result

Export all functions.

Create tests in src/lib/security/token-check.test.ts covering all behaviors.

Run: npm test -- --filter=token-check
